# manif-geom-rs

[![Build and Test](https://github.com/goromal/manif-geom-rs/actions/workflows/test.yml/badge.svg)](https://github.com/goromal/manif-geom-rs/actions/workflows/test.yml)

Rust implementations of the `SO(2)`, `SE(2)`, `SO(3)`, and `SE(3)` Lie groups,
matching the conventions and core API of
[manif-geom-cpp](https://github.com/goromal/manif-geom-cpp). The linear algebra
types come from [nalgebra](https://nalgebra.org/), which is re-exported as
`manif_geom_rs::na` so downstream code can use the exact compatible version.

## Supported groups

| Group | Generic type | `f64` alias | Coefficient order | Tangent order |
| --- | --- | --- | --- | --- |
| 2D rotation | `SO2<T>` | `SO2d` | `[qw, qx]` | `[angle]` |
| 2D transform | `SE2<T>` | `SE2d` | `[tx, ty, qw, qx]` | `[vx, vy, angle]` |
| 3D rotation | `SO3<T>` | `SO3d` | `[qw, qx, qy, qz]` | `[rx, ry, rz]` |
| 3D transform | `SE3<T>` | `SE3d` | `[tx, ty, tz, qw, qx, qy, qz]` | `[vx, vy, vz, rx, ry, rz]` |

All four types provide identity/random construction, contiguous coefficient
access, normalization, matrix conversion, inverse and composition, point
actions, exponential/logarithmic maps, right-side `oplus`/`ominus`, tangent
scaling, `f32`/`f64` casts, and owned/reference operator variants.

## Example

```rust
use manif_geom_rs::{na, SE3d, SO3d};

let rotation = SO3d::from_euler(&0.1, &0.2, &0.3);
let transform = SE3d::from_parts(na::Vector3::new(1.0, 2.0, 3.0), rotation);
let point = na::Vector3::new(0.5, -0.25, 1.0);

let transformed = transform * point;
let recovered = transform.inverse() * transformed;
assert!((recovered - point).norm() < 1.0e-12);
```

Add the crate from GitHub:

```toml
[dependencies]
manif-geom-rs = { git = "https://github.com/goromal/manif-geom-rs" }
```

## Conventions and invariants

- Quaternion-like coefficients are scalar-first, as in `manif-geom-cpp`.
- Composition is left-to-right group multiplication: `a * b` applies `b`,
  then `a`.
- Perturbations are applied on the right: `x + delta == x * Exp(delta)`.
- Group subtraction is `x - y == Log(y.inverse() * x)`.
- Raw coefficient constructors and mutable coefficient access preserve exactly
  what the caller supplies. Call `normalize()` or `normalized()` when unit
  coefficients are required.
- `SO3` and `SE3` logarithms accept both signs of a unit quaternion and return
  the canonical shortest rotation vector.

The test suite includes deterministic golden values generated by the C++
implementation, public-consumer integration tests, small-angle and quaternion
double-cover regressions, all operator variants, and debug/release checks.
